HOW THE AI GUARDIAN DECIDES

Not everything here is an agent.

Some parts of Safety Net score and predict. One part actually reasons and acts on its own — deciding when to wait, when to check in, and when to escalate without asking permission first. This page shows exactly which is which.

⌁ Agentic — plans & acts autonomously◇ Scored — rule/ML based, no autonomy
ESCALATION AGENT · LIVE REASONING TRACE● SIMULATED

Run a scenario to watch the agent reason step by step, the same way it would on a real trip.

TIER 0

Monitor

Background signal collection only. No contact, no alerts — the agent is just watching.

TIER 1

Check in

A private, gentle prompt goes to the user first. The agent always asks before it tells anyone else.

TIER 2 → 3

Escalate

No response, or signals compound: the agent independently calls the guardian, then the emergency contact, with a live location — no human approves each step.

SYSTEM BREAKDOWN

AGENTIC

Escalation Agent

Observes signals over time, weighs severity, chooses a response tier, and calls tools (check-in, voice dispatch, SMS) in sequence without a human approving each step. This is the one part of the system making autonomous decisions.

SCORED

Route Safety Index

A weighted score (lighting, foot traffic, verified safe havens) computed once when a route is requested. No ongoing decisions — closer to a recommendation engine than an agent.

SCORED

Anomaly Detection

Threshold-based checks on GPS/accelerometer data (stopped too long, off-route too far). Flags conditions for the Escalation Agent to reason over — it doesn't decide anything itself.
